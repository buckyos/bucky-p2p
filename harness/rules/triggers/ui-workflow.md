# UI, Presentation, And Workflow Trigger

## Required Coverage
- Design identifies affected UI states, navigation, validation, localization, accessibility semantics, and frontend/backend data contracts.
- Testing covers the changed user workflow, including relevant empty, loading, error, keyboard, and accessibility paths, or records a manual validation path.

## Reviewer Focus
- Check broken states, data mismatches, inaccessible controls, layout overlap, behavioral copy changes, and workflow regressions.
