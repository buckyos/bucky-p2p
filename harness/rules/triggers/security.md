# Security, Privacy, And Permission Trigger

## Required Coverage
- Proposal or design names the affected trust boundary, identities, allowed and denied cases, secret/token handling, privacy impact, and audit expectations.
- Testing includes negative or abuse cases for authentication, authorization, tenant isolation, input validation, and denied access where applicable.

## Reviewer Focus
- Check fail-open behavior, confused-deputy paths, information leaks, unsafe defaults, injection, insecure transport/storage, and sensitive logging.
